# 实验设计：机器学习模型对比 — KNN、决策树、随机森林在Iris数据集上的比较

**阶段：实验设计 (Experiment Design)**
**日期：2026-05-28**

---

## 1. 假设选择

### 选中的假设：假设 #1（最高优先级）— 超参数敏感性差异

**选择理由：**

1. **基础性最强**：假设#1是所有后续假设的基础。它输出每个模型的最优超参数，为假设#2（性能等价性）和假设#3（类别级差异）提供最优模型配置。如果不先确定最优参数，后续比较将缺乏公平性。

2. **新颖性高**：现有教学示例大多使用scikit-learn默认参数（KNN的k=5，决策树的max_depth=None，随机森林的n_estimators=100），缺乏对超参数-性能关系的系统性分析。文献综述确认这是一个重要研究空白。

3. **可行性最高**：仅需scikit-learn内置的Iris数据集（无需额外数据下载），计算量适中（扫描约25个参数配置，每个配置5次×10折=50次评估），可在2分钟内完成。

4. **产出价值大**：提供可操作的超参数调优指南，直接指导教学实践中的模型选择。

### 整体实验策略：5个假设依次执行

```
Phase A: 假设#1 (超参数敏感性) ──→ 输出最优超参数
    ↓
Phase B: 假设#2 (性能等价性) ── 使用Phase A输出的最优参数
    ↓
Phase C: 假设#3 (类别级差异) ── 使用Phase A输出的最优参数
    ↓
Phase D: 假设#4 (规模敏感性) ── 使用Phase A输出的最优参数（独立验证）
    ↓
Phase E: 假设#5 (特征鲁棒性) ── 使用Phase A输出的最优参数（独立验证）
```

## 2. 数据

### 2.1 数据集：scikit-learn内置Iris数据集

**来源：** `sklearn.datasets.load_iris()` — 无需额外下载

**数据集特性：**

| 属性 | 值 |
|------|-----|
| 样本数 | 150（每类50个，完全平衡） |
| 特征数 | 4（连续数值型） |
| 特征名称 | sepal length (cm), sepal width (cm), petal length (cm), petal width (cm) |
| 类别数 | 3（0=Setosa, 1=Versicolor, 2=Virginica） |
| 缺失值 | 无 |
| 特征类型 | 全部连续数值型 |

**数据集的经典统计特性：**

| 特征 | Setosa均值 | Versicolor均值 | Virginica均值 | 类间分离度 |
|------|-----------|--------------|-------------|-----------|
| 花萼长度 | 5.01 | 5.94 | 6.59 | 部分重叠 |
| 花萼宽度 | 3.43 | 2.77 | 2.97 | 部分重叠 |
| 花瓣长度 | 1.46 | 4.26 | 5.55 | **高度分离** |
| 花瓣宽度 | 0.25 | 1.33 | 2.03 | **高度分离** |

**数据预处理策略：**

| 模型 | 预处理 | 原因 |
|------|--------|------|
| KNN | `StandardScaler` 标准化 | KNN依赖欧氏距离，特征尺度不一致会扭曲距离计算 |
| 决策树 | 无标准化 | 树模型基于特征阈值分裂，对特征尺度不敏感 |
| 随机森林 | 无标准化 | 继承决策树的特性，对特征尺度不敏感 |

**注意：** 为公平对比，标准化**仅应用于KNN的输入**，不影响决策树和随机森林。这是各模型的最佳实践，不是不公平的优势。

### 2.2 数据划分策略

使用 **分层10折交叉验证 (Stratified 10-Fold Cross-Validation)**：

- **方法：** `StratifiedKFold(n_splits=10, shuffle=True, random_state=42)`
- **每折构成：** 约15个样本（每类5个），保持类别比例与原始数据一致
- **重复策略：** 每次实验重复5-10次，每次使用不同的随机种子（`random_state=42 + repeat`）
- **可复现性：** 所有随机操作使用固定种子

**为什么选择10折交叉验证？**
- Iris数据集只有150样本，留出法（如70/30划分）会导致测试集过小（仅45样本），统计不稳定
- 10折CV每折训练135样本、测试15样本，是样本利用效率最高的验证方式
- 分层确保每折类别比例一致，避免某折缺失某个类别

## 3. 基线方法

### 3.1 模型定义

| 模型 | scikit-learn类 | 默认参数 | 待调优超参数 | 固定参数 |
|------|---------------|---------|-------------|---------|
| **KNN** | `KNeighborsClassifier` | n_neighbors=5 | **n_neighbors** (k值) | metric='euclidean', weights='uniform' |
| **决策树** | `DecisionTreeClassifier` | max_depth=None | **max_depth** (最大深度) | criterion='gini', min_samples_split=2 |
| **随机森林** | `RandomForestClassifier` | n_estimators=100 | **n_estimators** (树数量) | criterion='gini', max_depth=None, max_features='sqrt' |

### 3.2 为什么选择这些超参数？

| 模型 | 选择的超参数 | 理由 |
|------|------------|------|
| KNN | k值（邻居数量） | 控制偏差-方差权衡的核心参数，直接影响决策边界的平滑度 |
| 决策树 | max_depth（最大深度） | 控制树复杂度的最直观参数，对过拟合/欠拟合影响最大 |
| 随机森林 | n_estimators（树数量） | Breiman (2001) 证明该参数控制收敛性，是集成效果的关键 |

**未调优的参数及其原因：**
- 距离度量（KNN）：统一使用欧氏距离，避免引入额外变量
- 分裂准则（决策树/随机森林）：统一使用基尼系数，信息增益在Iris上结果相似
- 最小样本分裂数：保持默认值2，不增加实验复杂度

## 4. 评估指标

### 4.1 核心分类性能指标

| 指标 | 定义 | 适用范围 | 说明 |
|------|------|---------|------|
| **准确率 (Accuracy)** | (TP+TN)/(TP+TN+FP+FN) | Phase A, B, D, E | 整体正确分类比例，适合完全平衡的Iris数据集 |
| **精确率 (Precision)** | TP/(TP+FP) (macro平均) | Phase C | 每类预测结果的"精确度"，macro平均赋予每类相同权重 |
| **召回率 (Recall)** | TP/(TP+FN) (macro平均) | Phase C | 每类真实样本被"找回"的比例 |
| **F1-Score** | 2×P×R/(P+R) (macro平均) | Phase C | 精确率与召回率的调和平均，综合评估 |
| **混淆矩阵** | 3×3矩阵 | Phase C | 展示各类别间的分类混淆情况 |

### 4.2 统计检验指标

| 检验方法 | 用途 | 适用Phase | 校正方法 |
|---------|------|-----------|---------|
| **配对t检验** | 两两模型准确率差异的显著性检验 | Phase B | Bonferroni校正（3次比较，α'=0.05/3≈0.0167） |
| **Cohen's d** | 效应量大小评估（d<0.2=小，0.2-0.5=中，>0.5=大） | Phase B | — |
| **Shapiro-Wilk** | 正态性检验（确保t检验的适用前提） | Phase B | — |
| **Friedman检验** | 三组非参数比较（ANOVA的非参数替代） | Phase B | — |
| **Wilcoxon符号秩检验** | 两两非参数比较（配对t检验的非参数替代） | Phase B | Bonferroni校正 |
| **McNemar检验** | 分类一致性检验（比较模型在哪些样本上不一致） | Phase C | — |

### 4.3 辅助指标

| 指标 | 用途 |
|------|------|
| **标准差 (Std)** | 评估模型在不同数据划分下的稳定性 |
| **95%置信区间** | 估计总体准确率的范围 |
| **训练时间** | 评估计算成本（仅记录，不纳入核心分析） |

## 5. 实验协议（逐步执行）

### Phase A: 假设#1 — 超参数敏感性差异

**目标：** 系统分析三个模型对各自核心超参数的敏感性，确定每个模型的最优超参数配置。

**理论预期：** KNN呈倒U型曲线（k=3~7最优），决策树呈对数饱和曲线（depth=3~4最优），随机森林呈单调收敛曲线（n>50稳定）。

---

#### 步骤 A1：KNN超参数扫描

**参数范围：** k = [1, 3, 5, 7, 9, 11, 15, 21]

**固定参数：** metric='euclidean', weights='uniform'

**伪代码：**
```
for each k in [1, 3, 5, 7, 9, 11, 15, 21]:
    重复5次:
        for each fold in 10折分层交叉验证:
            训练集: StandardScaler标准化
            测试集: 用训练集的scaler转换
            创建KNeighborsClassifier(n_neighbors=k)
            训练并预测
            记录准确率
    计算平均准确率和标准差
输出: k值 vs 准确率曲线, 最优k值
```

**输出：**
- CSV文件：`knn_sensitivity.csv`（每个k值的准确率均值和标准差）
- 图表：`knn_k_sensitivity.png`（误差曲线图，标注最优k值）

---

#### 步骤 A2：决策树超参数扫描

**参数范围：** max_depth = [1, 2, 3, 4, 5, 6, 8, 10, None]
- `None` 表示树完全生长（不限制深度）

**固定参数：** criterion='gini', min_samples_split=2

**伪代码：**
```
for each depth in [1, 2, 3, 4, 5, 6, 8, 10, None]:
    重复5次:
        for each fold in 10折分层交叉验证:
            不需要特征标准化
            创建DecisionTreeClassifier(max_depth=depth, criterion='gini')
            训练并预测
            记录准确率
    计算平均准确率和标准差
输出: max_depth vs 准确率曲线, 最优max_depth
```

**输出：**
- CSV文件：`dt_sensitivity.csv`（每个depth值的准确率均值和标准差）
- 图表：`dt_depth_sensitivity.png`（误差曲线图，标注最优depth值）

---

#### 步骤 A3：随机森林超参数扫描

**参数范围：** n_estimators = [1, 5, 10, 20, 50, 100, 200, 500]

**固定参数：** criterion='gini', max_depth=None, random_state=42

**伪代码：**
```
for each n in [1, 5, 10, 20, 50, 100, 200, 500]:
    重复5次:
        for each fold in 10折分层交叉验证:
            不需要特征标准化
            创建RandomForestClassifier(n_estimators=n, random_state=42)
            训练并预测
            记录准确率
    计算平均准确率和标准差
输出: n_estimators vs 准确率曲线, 最优n_estimators
```

**输出：**
- CSV文件：`rf_sensitivity.csv`（每个n值的准确率均值和标准差）
- 图表：`rf_estimators_sensitivity.png`（误差曲线图，标注最优n值）

---

#### 步骤 A4：汇总输出

**输出文件：**
- **`best_hyperparameters.csv`**：三个模型的最优超参数汇总

| Model | Best_Hyperparameter | Best_Accuracy |
|-------|-------------------|--------------|
| KNN | k=15 | 0.9613 |
| 决策树 | max_depth=4 | 0.9493 |
| 随机森林 | n_estimators=100 | 0.9587 |

### Phase B: 假设#2 — 模型性能等价性

**目标：** 使用Phase A确定的最优超参数，检验三个模型的准确率是否存在统计显著的差异。

**理论预期：** 三模型在Iris数据集上无统计显著差异（配对t检验p>0.0167，Bonferroni校正后）。

---

#### 步骤 B1：最优配置下的重复交叉验证

**模型配置（来自Phase A）：**
- KNN: k=最优值, metric='euclidean', 需要标准化
- 决策树: max_depth=最优值, criterion='gini', 不需要标准化
- 随机森林: n_estimators=最优值, max_depth=None, 不需要标准化

**实验流程：**
```
重复10次（random_state=42, 43, ..., 51）:
    for each fold in 10折分层交叉验证:
        训练并评估KNN（标准化）
        训练并评估决策树（不标准化）
        训练并评估随机森林（不标准化）
        记录三个模型的准确率
→ 每个模型获得 10次×10折 = 100个准确率样本
```

---

#### 步骤 B2：统计检验流水线

**检验流程（按优先级）：**
```
1. 正态性检验 (Shapiro-Wilk):
   - 对每个模型的100个准确率样本
   - H0: 数据服从正态分布
   - 如果p>0.05 → 可用参数检验

2. 三组比较 (Friedman检验):
   - 非参数重复测量方差分析
   - H0: 三模型的准确率中位数相同
   - 如果p<0.05 → 至少有一对模型存在差异

3. 两两比较 (配对t检验):
   - 3次比较: KNN vs 决策树, KNN vs 随机森林, 决策树 vs 随机森林
   - Bonferroni校正: α' = 0.05/3 ≈ 0.0167
   - H0: 两模型准确率均值无差异
   - 报告: t统计量, p值, 是否显著

4. 效应量 (Cohen's d):
   - d = |mean_diff| / std_diff
   - 解释: 小(d<0.2), 中(0.2≤d<0.5), 大(d≥0.5)

5. 非参数验证 (Wilcoxon符号秩检验):
   - 配对t检验的非参数替代
   - 同样使用Bonferroni校正
```

### Phase C: 假设#3 — 类别级性能差异

**实验流程：**
```

```

**评估维度：**
| 模型 | Setosa F1 | Versicolor F1 | Virginica F1 | 困难类F1总和 |
|------|-----------|--------------|-------------|-------------|

| 决策树 | 预期≈1.0 | 预期≈0.91 | 预期≈0.91 | 预期≈1.82 |
| 随机森林 | 预期≈1.0 | 预期≈0.94 | 预期≈0.94 | 预期≈1.88 |

---

#### 步骤 C2：McNemar检验

**目的：** 检验两个模型在哪些样本上分类结果不一致，判断分类一致性。

**计算方法：**
```
对于每对模型 (M1, M2):
    构建2×2列联表:
    ┌─────────────────┬─────────────────┐
    │ 两者都正确(n00) │ M1正确 M2错误(n01)│
    ├─────────────────┼─────────────────┤
    │ M1错误 M2正确(n10)│ 两者都错误(n11) │
    └─────────────────┴─────────────────┘
    
    χ² = (|n01 - n10| - 1)² / (n01 + n10)
    df = 1
    p = 1 - χ².cdf(χ²_stat, 1)
```

### Phase D: 假设#4 — 训练集规模敏感性

**目标：** 分析训练集规模对三个模型性能的影响，确定各模型在小样本场景下的鲁棒性。

**理论预期：** KNN衰减最快，随机森林最鲁棒。

---

#### 步骤 D1：学习曲线实验

**对应样本数：** [15, 30, 45, 60, 75, 105, 127]

**实验流程：**
```

        StratifiedShuffleSplit(test_size=1-ratio, random_state=42+repeat)
        训练并评估三个模型（使用最优参数）
        记录测试集准确率
→ 每个比例下10个准确率样本/模型
```

**数据记录格式：**
| train_ratio | train_samples | model | mean_accuracy | std_accuracy |
|------------|--------------|-------|--------------|-------------|
| 0.10 | 15 | KNN | ... | ... |
| 0.10 | 15 | 决策树 | ... | ... |
| ... | ... | ... | ... | ... |

### Phase E: 假设#5 — 特征子集鲁棒性

**目标：** 分析不同特征子集对三个模型性能的影响。

**理论预期：** 花瓣特征几乎与全特征同等有效；仅用花萼特征时，决策树降幅最小，随机森林降幅最大。

---

#### 步骤 E1：特征子集实验

**特征子集方案：**

| 编号 | 名称 | 特征索引 | 特征数量 | 描述 |
|------|------|---------|---------|------|
| F1 | 全部特征 | [0, 1, 2, 3] | 4 | 花萼长度+宽度 + 花瓣长度+宽度 |
| F2 | 仅花瓣 | [2, 3] | 2 | 花瓣长度 + 花瓣宽度 |
| F3 | 仅花萼 | [0, 1] | 2 | 花萼长度 + 花萼宽度 |
| F4 | 花萼长+花瓣长 | [0, 2] | 2 | 长度组合 |
| F5 | 花萼宽+花瓣宽 | [1, 3] | 2 | 宽度组合 |

**模型配置：** 使用Phase A确定的最优超参数

**实验流程：**
```
for each feature subset in [F1, F2, F3, F4, F5]:
    重复5次:
        10折分层交叉验证:
```

## 6. 混杂因素控制

| 潜在混杂因素 | 影响 | 控制措施 |
|-------------|------|---------|
| **数据划分随机性** | 不同的数据划分可能导致不同的性能评估结果 | 固定随机种子 (`random_state=42`)，重复实验（5-10次）取平均 |
| **交叉验证折数** | 折数影响偏差-方差权衡 | 统一使用10折分层交叉验证 |
| **超参数选择偏倚** | 手动选择超参数可能偏向某个模型 | Phase A中系统扫描所有参数值，非手动选择 |
| **实现差异** | 不同框架的实现可能影响性能 | 全部使用scikit-learn统一框架 |
| **特征缩放** | 某些模型对特征尺度敏感 | KNN使用标准化，树模型使用原始值（各自最优实践） |
| **随机森林随机性** | Bootstrap采样和随机特征选择引入随机性 | 固定random_state，多次重复取均值 |
| **多重比较** | 多次检验增加I类错误概率 | Bonferroni校正（α'=0.05/3≈0.0167） |
| **类别不平衡** | 模型可能偏向多数类 | Iris数据集完全平衡（每类50样本），分层采样保持平衡 |

## 10. 成功标准与验证

### 10.1 假设检验标准

| 假设 | 确认标准（支持假设） | 否证标准（反驳假设） |
|------|-------------------|-------------------|
| **H1: 超参数敏感性** | KNN倒U型峰在k=3~7；DT在depth=3~4饱和；RF在n>50稳定 | KNN单调变化；DT持续提升；RF过拟合下降 |
| **H2: 性能等价性** | 三模型配对t检验p>0.0167（Bonferroni校正后） | 任一对比p<0.0167 |
| **H3: 类别级差异** | Setosa F1=1.0；RF在困难类F1最高 | KNN在困难类最优；差异<0.5% |
| **H4: 规模敏感性** | 训练集减至30时KNN下降>8%，DT~5%，RF<4% | 下降幅度相近（差异<2%） |
| **H5: 特征鲁棒性** | 特征减少时DT降幅最小，RF降幅最大 | 降幅一致；KNN最不敏感 |

## 11. 实验设计总结

本实验设计围绕5个假设构建了从**超参数敏感性**（Phase A）到**性能等价性**（Phase B）、**类别级差异**（Phase C）、**规模敏感性**（Phase D）和**特征鲁棒性**（Phase E）的完整实验流水线。

**实验设计的核心优势：**
1. ✅ **系统性**：5个Phase逐步推进，后一Phase依赖前一Phase的输出
2. ✅ **严谨性**：使用重复分层10折交叉验证 + 统计显著性检验 + 多重比较校正
3. ✅ **可复现性**：固定随机种子 + 完整代码 + 详细协议
4. ✅ **全面性**：从全局准确率到类别级F1，从全特征到特征子集，从全量数据到小样本
5. ✅ **实用性**：结果可直接指导Iris数据集上的模型选择和参数调优实践

**实验设计的核心局限：**
1. ⚠️ Iris数据集仅有150样本，结果的外部有效性有限
2. ⚠️ 仅测试了三个模型的核心超参数，未探索更多参数组合
3. ⚠️ 实验在单一数据集上进行，不适用于跨数据集的泛化结论
