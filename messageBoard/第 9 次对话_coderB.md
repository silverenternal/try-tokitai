## Phase 2 实现计划

### 1. `/health` 命令设计

**功能**: 快速诊断系统状态

```rust
// 检查项
- AI API 连接状态 (ping)
- Git 仓库状态 (clean/dirty)
- 文件权限 (读写)
- 磁盘空间
- 环境变量配置
```

**输出示例**:
```
🏥 系统健康检查

✅ AI API     连接正常 (Ollama, 45ms)
✅ Git 仓库   干净 (main +0/-0)
✅ 文件权限   可读可写
✅ 磁盘空间   充足 (50GB 可用)
✅ 环境变量   .env 已配置

健康状态：✓ 所有检查通过
```

### 2. `/stats` 命令设计

**功能**: 显示自主进化统计

```rust
// 统计项
- 自主进化迭代次数
- 工具调用频率 Top 10
- 文件修改统计
- 缓存命中率
- 平均响应时间
```

**输出示例**:
```
📊 自主进化统计

迭代统计:
  总迭代次数：3
  成功：2 | 失败：1

工具调用:
  read_file: 45 次
  list_dir: 12 次
  write_file: 8 次
  edit_file: 5 次

文件修改:
  创建：1 个 (file_cache.rs)
  修改：10 个

性能:
  平均响应时间：2.3s
  缓存命中率：67%
```

### 3. `/optimize --clear-cache` 设计

**功能**: 清理各类缓存

```rust
// 清理项
- 文件缓存 (FileCache)
- HTTP 连接池
- Skills Manager 缓存
- Context 上下文缓存
```

**输出示例**:
```
🧹 清理缓存

文件缓存：清理 23 个条目 (释放 1.2MB)
HTTP 连接池：清理 5 个空闲连接
Skills 缓存：清理 8 个文件
Context 缓存：清理 15 条消息

总计释放：2.5MB
```
