# FileKV Query → Bloom Filter Result 架构详解

## 完整查询流程图

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                          FileKV.get(key) 入口                                    │
└─────────────────────────────────────────┬───────────────────────────────────────┘

                                          ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│ Stage 1: MemTable 检查 (DashMap)                                                │
│  ├─ 命中且有值 → 返回 value ✅ END                                               │
│  ├─ 命中且 tombstone → 返回 None ✅ END                                          │
│  └─ 未命中 → 继续                                                                │
└─────────────────────────────────────────┬───────────────────────────────────────┘
                                          │
                                          ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│ Stage 2: BlockCache 检查 (LRU 热数据块缓存)                                       │
│  ├─ 命中 → 返回 cached value ✅ END                                              │
│  └─ 未命中 → 继续                                                                │

                                          │
                                          ▼

│                                                                                 │
│  ┌───────────────────────────────────────────────────────────────────────────┐  │

│  │     index.find(key) → 获取 position (如果有)                               │  │
│  └─────────────────────────────────────┬─────────────────────────────────────┘  │
│                                        │                                         │
│                                        ▼                                         │
│  ┌───────────────────────────────────────────────────────────────────────────┐  │

│                                        ▼                                         │
│  ┌───────────────────────────────────────────────────────────────────────────┐  │

│  │                                   ▼                                       │  │

│  │  │  ┌──────────────────────────────────────────────────────────┐    │    │  │

│  │  │  └──────────────────────────────────────────────────────────┘    │    │  │
│  │  │                                                                  │    │  │
│  │  │  DashMap.get(&segment_id)                                        │    │  │

│  │  └─────────────────────────────┬────────────────────────────────────┘    │  │
│  │                                │                                         │  │
│  │                                ▼                                         │  │
│  │  ┌──────────────────────────────────────────────────────────────────┐    │  │

│  │  │  ┌──────────────────────────────────────────────────────────┐    │    │  │

│  │  │  │ 容量: 10,000 filters                                     │    │    │  │
│  │  │  │ FPR: 1%                                                  │    │    │  │
│  │  │  │ 延迟: ~500ns (需解压)                                     │    │    │  │
│  │  │  │ 压缩: RLE + Huffman (CompressedBloom)                    │    │    │  │
│  │  │  └──────────────────────────────────────────────────────────┘    │    │  │
│  │  │                                                                  │    │  │
│  │  │  DashMap.get(&segment_id)                                        │    │  │

│  │  │  │      → FALL THROUGH 到 Step C                                 │    │  │
│  │  │  └─ MISS → 继续 Step C                                           │    │  │
│  │  └─────────────────────────────┬────────────────────────────────────┘    │  │
│  │                                │                                         │  │
│  │                                ▼                                         │  │
│  │  ┌──────────────────────────────────────────────────────────────────┐    │  │
│  │  │  Step C: L3 Disk Load (Cold Storage)                             │    │  │
│  │  │  ┌──────────────────────────────────────────────────────────┐    │    │  │
│  │  │  │ 组件: BloomFilterMigrator.load_with_migration()          │    │    │  │
│  │  │  │ FPR: 10%                                                 │    │    │  │
│  │  │  │ 延迟: ~10µs                                              │    │    │  │
│  │  │  │ 路径: index/bloom_{segment_id:06}.bin                    │    │    │  │
│  │  │  └──────────────────────────────────────────────────────────┘    │    │  │
│  │  │                                                                  │    │  │
│  │  │  total_misses++                                                  │    │  │
│  │  │  1. 打开文件，读取 header (magic + version)                       │    │  │
│  │  │  2. 读取 num_keys + 所有 keys                                    │    │  │
│  │  │  3. 重建 BloomFilter: BloomFilter.with_rate(0.01, num_keys)      │    │  │
│  │  │  4. 版本迁移检查 (MigrationResult)                                │    │  │
│  │  │                                                                  │    │  │
│  │  │  ├─ SUCCESS → l3_hits++                                          │    │  │
│  │  │  │           l3_to_l2_migrations++                                │    │  │
│  │  │  │           insert_l1_arc(segment_id, Arc<BloomFilter>)          │    │  │
│  │  │  │           → 返回 Arc<BloomFilter> → Step E                    │    │  │
│  │  │  └─ FILTER NOT FOUND → 返回 None → 跳过 Bloom 检查 → Step F     │    │  │
│  │  └──────────────────────────────────────────────────────────────────┘    │  │
│  │                                                                           │  │
│  │  ┌──────────────────────────────────────────────────────────────────┐    │  │
│  │  │  Step D: Feature Flag DISABLED 路径                              │    │  │
│  │  │  loader(segment_id) → 直接磁盘加载 → 返回 Arc<BloomFilter>       │    │  │
│  │  │  → Step E                                                         │    │  │
│  │  └──────────────────────────────────────────────────────────────────┘    │  │
│  │                                                                           │  │
│  │  ┌──────────────────────────────────────────────────────────────────┐    │  │
│  │  │  Step E: BloomFilter.contains(key)                               │    │  │
│  │  │  ├─ FALSE → Key 确定不存在                                        │    │  │
│  │  │  │       bloom_filtered++                                        │    │  │
│  │  │  │       → 跳过该 segment，检查下一个 segment                      │    │  │
│  │  │  └─ TRUE → Key 可能存在 (有误判)                                  │    │  │
│  │  │          → 继续稀疏索引查找 + SegmentFile.read_at()               │    │  │
│  │  └──────────────────────────────────────────────────────────────────┘    │  │
│  │                                                                           │  │
│  │  ┌──────────────────────────────────────────────────────────────────┐    │  │
│  │  │  Step F: 后台迁移检查                                             │    │  │
│  │  │  MigrationController.record_access(segment_id)                   │    │  │
│  │  │  ├─ 更新 tracker (access_count, QPS)                             │    │  │
│  │  │  ├─ decide_migration(&record) 检查迁移需求                        │    │  │
│  │  │  └─ 如需迁移 → 加入 pending_migrations                           │    │  │
│  │  └──────────────────────────────────────────────────────────────────┘    │  │
│  │                                                                           │  │
│  └───────────────────────────────────────────────────────────────────────┘  │  │
│                                        │                                      │  │
│                                        ▼                                      │  │
│  ┌────────────────────────────────────────────────────────────────────────┐  │  │
│  │ 如果 Bloom = TRUE (可能存在):                                           │  │  │
│  │  3c. IndexManager 查找 position → SegmentFile.read_at()                │  │  │
│  │  ├─ 找到 → BlockCache.insert() → 返回 value ✅                         │  │  │
│  │  └─ 未找到 → 继续下一个 segment                                         │  │  │
│  └────────────────────────────────────────────────────────────────────────┘  │  │
│                                                                              │  │
└──────────────────────────────────────────────────────────────────────────────┘  │
                                                                                  │
  所有 segment 都未找到 → 返回 None ✅                                             │
                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## L1/L2/L3 升级/降级详细流程

### 升级路径 (Upgrade)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        L3 → L2 → L1 升级流程                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  L3 (Cold, Disk) ──upgrade──→ L2 (Warm, Compressed) ──upgrade──→ L1 (Hot)  │
│                                                                             │
│  ┌─────────────────────────┐    ┌─────────────────────────┐                 │
│  │ L3 → L2 升级             │    │ L2 → L1 升级             │                 │
│  │                         │    │                         │                 │
│  │ Trigger:                │    │ Trigger:                │                 │
│  │   QPS > 10 (warm)       │    │   QPS > 100 (hot)       │                 │
│  │   持续 60s              │    │   持续 60s              │                 │
│  │                         │    │                         │                 │
│  │ Action:                 │    │ Action:                 │                 │
│  │   从磁盘加载 BloomFilter │    │   解压 CompressedBloom   │                 │
│  │   插入 L2 缓存          │    │   插入 L1 缓存          │                 │
│  │                         │    │                         │                 │
│  │ Stats:                  │    │ Stats:                  │                 │
│  │   l3_to_l2_migrations++ │    │   l2_to_l1_migrations++ │                 │
│  │                         │    │                         │                 │
│  │ Benefit:                │    │ Benefit:                │                 │
│  │   10µs → 500ns          │    │   500ns → <100ns        │                 │
│  │                         │    │                         │                 │
│  │ ⚠️ 当前 L2 压缩禁用      │    │ ⚠️ 依赖 L2 解压功能     │                 │
│  │   实际直接从 L3 到 L1    │    │   当前不可用             │                 │
│  └─────────────────────────┘    └─────────────────────────┘                 │
│                                                                             │
│  升级判定过程 (FPRController):                                               │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │ 1. record_access(segment_id, AccessRecord)                       │      │
│  │ 2. 计算 QPS = window_count / (window_duration_ms / 1000)         │      │
│  │ 3. determine_target_level(QPS):                                  │      │
│  │    ┌──────────────────────────────────────────────────────┐     │      │
│  │    │ QPS >= 100  → Level 0 (FPR 0.1%, 内存 2.0x)         │     │      │
│  │    │ QPS >= 50   → Level 1 (FPR 0.5%, 内存 1.5x)         │     │      │
│  │    │ QPS >= 10   → Level 2 (FPR 1.0%, 内存 1.0x) [默认]  │     │      │
│  │    │ QPS >= 5    → Level 3 (FPR 2.0%, 内存 0.75x)        │     │      │
│  │    │ QPS >= 1    → Level 4 (FPR 5.0%, 内存 0.5x)         │     │      │
│  │    │ QPS >= 0    → Level 5 (FPR 10.0%, 内存 0.25x)       │     │      │
│  │    └──────────────────────────────────────────────────────┘     │      │
│  │ 4. 检查 stabilization_window (120s 内不调整)                    │      │
│  │ 5. 检查 hysteresis (滞后因子 0.2, 防止振荡)                      │      │
│  │ 6. 如果 gradual_transitions 启用且跨度>1 → 每次±1级             │      │
│  │ 7. 应用新 level                                                  │      │
│  └──────────────────────────────────────────────────────────────────┘      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 降级路径 (Downgrade)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        L1 → L2 → L3 降级流程                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  L1 (Hot) ──downgrade──→ L2 (Warm, Compressed) ──downgrade──→ L3 (Cold)    │
│                                                                             │
│  ┌─────────────────────────┐    ┌─────────────────────────┐                 │
│  │ L1 → L2 降级 (冷却)      │    │ L2 → L3 降级 (驱逐)      │                 │
│  │                         │    │                         │                 │
│  │ Trigger:                │    │ Trigger:                │                 │
│  │   QPS < 5 (cooldown)    │    │   QPS < 1 (cold)        │                 │
│  │   持续 300s             │    │   持续 300s             │                 │
│  │                         │    │                         │                 │
│  │ Action:                 │    │ Action:                 │                 │
│  │   L1 LRU 淘汰时         │    │   L2 LRU 淘汰时         │                 │
│  │   压缩后存入 L2         │    │   仅保留磁盘文件         │                 │
│  │                         │    │                         │                 │
│  │ Stats:                  │    │ Stats:                  │                 │
│  │   l1_to_l2_migrations++ │    │   l2_to_l3_migrations++ │                 │
│  │                         │    │                         │                 │
│  │ Benefit:                │    │ Benefit:                │                 │
│  │   释放 L1 空间给热数据   │    │   释放 L2 内存          │                 │
│  │   L2 压缩节省内存        │    │   冷数据按需加载         │                 │
│  │                         │    │                         │                 │
│  │ ⚠️ 当前 L2 压缩禁用      │    │                         │                 │
│  │   实际仅从 L1 删除       │    │                         │                 │
│  └─────────────────────────┘    └─────────────────────────┘                 │
│                                                                             │
│  降级判定过程 (MigrationController):                                         │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │ 1. tracker.record_access() 更新访问计数                          │      │
│  │ 2. 计算 QPS = window_count / (window_duration_ms / 1000)         │      │
│  │ 3. decide_migration(&record):                                    │      │
│  │    ┌──────────────────────────────────────────────────────┐     │      │
│  │    │ 当前 L1: QPS < 5 且持续 300s → DowngradeToL2        │     │      │
│  │    │ 当前 L2: QPS < 1 且持续 300s → DowngradeToL3        │     │      │
│  │    │ 当前 L2: QPS > 100 且持续 60s  → UpgradeToL1        │     │      │
│  │    │ 当前 L3: QPS > 10 且持续 60s   → UpgradeToL2        │     │      │
│  │    │ 否则 → Stay                                          │     │      │
│  │    └──────────────────────────────────────────────────────┘     │      │
│  │ 4. 如果需要迁移 → 加入 pending_migrations                        │      │
│  │ 5. complete_migration(segment_id, target_layer) 执行迁移         │      │
│  └──────────────────────────────────────────────────────────────────┘      │
│                                                                             │
│  LRU 驱逐机制:                                                              │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │ L1 Eviction:                                                     │      │
│  │   Trigger: l1_cache.len() >= 1000                               │      │
│  │   Process: evict_l1_multiple(10)                                 │      │
│  │     1. lru.pop_lru() → 获取最冷的 entry                          │      │
│  │     2. l1_cache.remove(&segment_id)                              │      │
│  │     3. l1_memory_used -= entry.memory_size                       │      │
│  │     4. l1_to_l2_migrations++                                     │      │
│  │     5. ⚠️ 当前不调用 insert_l2 (压缩禁用)                        │      │
│  │                                                                  │      │
│  │ L2 Eviction:                                                     │      │
│  │   Trigger: l2_cache.len() >= 10000                              │      │
│  │   Process: evict_l2()                                            │      │
│  │     1. lru.pop_lru() → 获取最冷的 entry                          │      │
│  │     2. l2_cache.remove(&segment_id)                              │      │
│  │     3. l2_memory_used -= entry.compressed.compressed_data.len()  │      │
│  │     4. l2_to_l3_migrations++                                     │      │
│  │     5. Filter 变为磁盘状态                                        │      │
│  └──────────────────────────────────────────────────────────────────┘      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 滞后因子 (Hysteresis) 防振荡机制

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         滞后因子防振荡机制                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  hysteresis_factor = 0.2 (20%)                                             │
│  stabilization_window = 120,000ms (2 分钟)                                   │
│                                                                             │
│  升级滞后:                                                                  │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │ 要升级到 Level 1 (FPR 0.5%, min_qps=50):                         │      │
│  │   实际要求: QPS >= 50 * (1.0 + 0.2) = 60 QPS                    │      │
│  │                                                                  │      │
│  │ 要升级到 Level 0 (FPR 0.1%, min_qps=100):                        │      │
│  │   实际要求: QPS >= 100 * (1.0 + 0.2) = 120 QPS                  │      │
│  └──────────────────────────────────────────────────────────────────┘      │
│                                                                             │
│  降级滞后:                                                                  │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │ 要从 Level 1 降级 (cooldown_threshold=5):                         │      │
│  │   实际要求: QPS <= 5 * (1.0 - 0.2) = 4 QPS                      │      │
│  │                                                                  │      │
│  │ 要从 Level 2 降级 (cold_threshold=1):                             │      │
│  │   实际要求: QPS <= 1 * (1.0 - 0.2) = 0.8 QPS                    │      │
│  └──────────────────────────────────────────────────────────────────┘      │
│                                                                             │
│  效果: 防止在阈值附近频繁切换 (如 QPS 在 49-51 之间振荡)                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 关键数据文件

| 文件 | 路径 | 作用 |
|------|------|------|
| Bloom Filter | `index/bloom_{segment_id:06}.bin` | L3 磁盘存储的 Bloom Filter |
| Segment | `segments/segment_{id}.log` | 实际 KV 数据段 |

## 当前限制

1. **L2 压缩/解压功能禁用**: 由于 `bloom` crate 不暴露 `false_positive_rate()` 和 `to_bits()` 方法，L2 缓存无法实际存储和恢复 Bloom Filter。L2 命中后会 fall through 到 L3。

2. **FPR 未应用到实际 Filter**: FPR Controller 追踪 segment 状态并调整级别，但实际的 Bloom Filter 在创建时使用固定 FPR (0.01)，尚未根据 FPR level 动态调整。

3. **迁移异步化不完整**: MigrationController 记录 pending migrations，但实际的 filter 移动操作（如 decompress、insert_l2）在当前实现中被禁用或简化。
