## 🗂️ 文档组织原则

### 文档分层

```
Level 1: 核心文档（必读）
├── README.md - 项目总览
├── 项目状态报告 - 最新进展
└── 论文规划 - 完整规划

Level 2: 分类文档（按需阅读）
├── 架构文档 - 系统设计
├── 用户文档 - 使用指南
├── 论文文档 - 研究相关
└── 实现文档 - 开发相关

Level 3: 归档文档（历史参考）
└── archive/ - 已完成的计划和报告
```

### 文档命名规范

- **计划文档**: `*_PLAN.json` 或 `*_PLAN.md`
- **实现报告**: `*_IMPLEMENTATION_REPORT.md` 或 `*_IMPLEMENTATION_SUMMARY.md`
- **设计文档**: `*_DESIGN.json` 或 `*_DESIGN.md`
- **用户指南**: `*_USER_GUIDE.md`
- **开发者指南**: `*_DEVELOPER_GUIDE.md`
- **状态报告**: `*_STATUS_REPORT.md` 或 `PROJECT_STATUS_*.md`

### 文档更新流程

1. **新增文档**: 在对应分类目录下创建，更新本索引
2. **更新文档**: 修改文档内容，更新"最后更新"日期
3. **归档文档**: 移动到 `archive/` 目录，更新本索引状态
4. **删除文档**: 谨慎操作，确保无外部引用
